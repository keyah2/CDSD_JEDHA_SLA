# CDSD — Projets d'examen JEDHA Bootcamp

Ce dépôt regroupe l'ensemble des projets réalisés dans le cadre du cursus **Certified Data Scientist & Developer (CDSD)** de JEDHA Bootcamp.

---

## Blocs

| Bloc | Projet | Compétences principales |
|------|--------|------------------------|
| [Bloc 1](./Bloc_1%20Kayak/) | **Kayak** — Recommandation de destinations de voyage | Web scraping, géocodage, SQL, visualisation cartographique |
| [Bloc 2 — EDA](./Bloc_2%20%20Tinder/) | **Tinder / Speed Dating** — Analyse des comportements de rencontre | Analyse exploratoire, statistiques descriptives |
| [Bloc 2 — NLP](./Bloc_2%20Steam/) | **Steam** — Analyse de reviews de jeux vidéo | NLP, traitement de texte |
| [Bloc 3 — ML](./Bloc_3%20Conversion%20rate%20challenge/) | **Conversion Rate Challenge** — Prédiction du taux de conversion | Machine Learning supervisé, classification |
| [Bloc 3 — EDA](./Bloc_3%20Uber%20Pickups/) | **Uber Pickups** — Analyse des zones chaudes à New York | Analyse temporelle et géospatiale |
| [Bloc 3 — ML](./Bloc_3%20Walmart%20Sales/) | **Walmart Sales** — Prévision des ventes hebdomadaires | Régression, feature engineering |
| [Bloc 4](./Bloc_4%20Deep%20Learning%20Project%20(AT%26T)/) | **AT&T Spam Detector** — Détection de spam par deep learning | NLP, LSTM, TensorFlow/Keras |
| [Bloc 5](./Bloc_5%20Getaround/) | **Getaround** — Pricing ML + Dashboard + API REST | MLflow, FastAPI, Streamlit, Docker |
| [Bloc 6](./Bloc_6%20G4%20ANTI%20FRAUD/) | **G4 Anti-Fraud** — Détection de fraude bancaire | XGBoost, MLflow, Streamlit, Docker |

---

## Stack technique

- **Langages** : Python, SQL
- **ML / DL** : scikit-learn, XGBoost, TensorFlow / Keras
- **MLOps** : MLflow, FastAPI, Docker
- **Visualisation** : Streamlit, Plotly, Folium
- **Données** : pandas, NumPy, requests, BeautifulSoup
